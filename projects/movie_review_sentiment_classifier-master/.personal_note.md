## ?? 1. Package Setup

Ensure setup.py includes:

setup(
    name='movie_review_sentiment_classifier',
    version='0.1',
    packages=find_packages(where='src'),
    package_dir={'': 'src'},
    install_requires=[
        'fastapi',
        'uvicorn',
        'scikit-learn',

        'joblib'
    ],

Install locally (for development):

pip install -e .

## ?? 2. Run the ML API (Python Service)

src/movie_review_sentiment_classifier/api.py

from fastapi import FastAPI
from pydantic import BaseModel
from joblib import load

app = FastAPI()
model = load("models/sentiment_model.pkl")

class Review(BaseModel):
    text: str

@app.post("/predict")
def predict_sentiment(review: Review):
    pred = model.predict([review.text])[0]
    return {"sentiment": pred}

Run locally:

uvicorn movie_review_sentiment_classifier.api:app --host 0.0.0.0 --port 8000

The API will serve predictions at:
?? http://localhost:8000/predict

## ?? 3. Integrate with Express.js (TypeScript Backend)

Express route example (/routes/predict.ts):

import express from "express";
import axios from "axios";

const router = express.Router();

router.post("/predict", async (req, res) => {
  try {
    const { text } = req.body;
    const response = await axios.post("http://ml-service:8000/predict", { text });
    res.json(response.data);
  } catch (err: any) {
    res.status(500).json({ error: "ML service unavailable" });
  }
});

export default router;

Server entry (/server.ts):

import express from "express";
import bodyParser from "body-parser";
import predictRoute from "./routes/predict";

const app = express();
app.use(bodyParser.json());
app.use("/api", predictRoute);

app.listen(3000, () => console.log("Express API running on port 3000"));

## ?? 4. Dockerization

### Python ML Service

Dockerfile

FROM python:3.10-slim
WORKDIR /app
COPY . .
RUN pip install --no-cache-dir -e .
EXPOSE 8000
CMD ["uvicorn", "movie_review_sentiment_classifier.api:app", "--host", "0.0.0.0", "--port", "8000"]

### Express Backend

Dockerfile

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install --production
COPY . .
EXPOSE 3000
CMD ["npm", "start"]

### docker-compose.yml

version: "3.8"
services:
  backend:
    build: ./express-backend
    ports:
      - "3000:3000"
    depends_on:
      - ml-service

  ml-service:
    build: ./python-ml-service
    ports:
      - "8000:8000"

Run everything:

docker compose up --build
